# Система защиты передачи подарков

## Как работает

После принятия офера продавцом появляется кнопка **"Подтвердить передачу"**.

### Время действия офера
- ⏰ Офер действует **24 часа** с момента создания
- После истечения срока офер автоматически становится недействительным

### Защита от мошенничества:

1. **Кулдаун 4 минуты** ⏳
   - После принятия офера нужно подождать **4 минуты** перед подтверждением
   - Это время дано на фактическую передачу подарка покупателю
   - Если нажать раньше, появится сообщение с оставшимся временем

2. **Однократное подтверждение** 🔒
   - Подтвердить передачу можно только **1 раз**
   - Повторные попытки будут отклонены

3. **Проверка статуса** ✅
   - Подтвердить можно только принятые оферы
   - Отклоненные или ожидающие оферы нельзя подтвердить

## Сообщения для пользователя

### Успешное подтверждение (после 4 минут)
```
Ваш подарок {название} успешно передан покупателю.

Денежные средства будут автоматически отправлены на Ваш аккаунт в течении 60м.
```

### Попытка подтвердить раньше времени
```
Подарок {название} не передан покупателю. Повторите попытку.

Вы сможете подтвердить передачу через Xм Yс.
```

### Повторное подтверждение
```
Передача подарка {название} уже подтверждена.
```

## Технические детали

- Время принятия записывается в поле `accepted_at`
- Факт подтверждения - в поле `transfer_confirmed`
- Время подтверждения - в поле `transfer_confirmed_at`
- Кулдаун: **240 секунд** (4 минуты)
